# 设计系统验收 · 0.1.10

2026-09-10 已完成代码、实际渲染、安装包和本机升级检查。截图中的旧绿色界面已由小狗/Logo 的暖白、棕色与焦糖色体系替代；本次重点将已有配色落实到统一组件、尺寸和开发约束。

## 实现

- Studio 与桌面设置从 `@petlord/ui` 使用 Ant Design 控件及 Radix 对话框；标准文本、选择器、按钮、复选框和开关共享行为与状态。
- `tokens.json` 同时生成 CSS 变量和 Ant Design 配置，覆盖两种主题、字号偏好、控件尺寸、圆角、间距和弹层层级。应用布局与控件绘制分开，移除 Select 外层重复边框。
- 新建项目使用可选形象下拉、角色预览和键盘可操作的模板 Radio。继续允许同一项目自由绘图、生成和导入，不增加制作路线。
- 项目 Skill 位于 `.agents/skills/petlord-design-system/SKILL.md`；根 `AGENTS.md` 引导后续界面开发使用它。`npm run check:design` 已加入完整检查，拒绝 token 漂移、原始表单绕行、局部字号/圆角/颜色和 Select 外层绘制。
