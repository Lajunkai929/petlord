# 像素陪伴 0.1.11 验证记录

日期：2026-09-10。环境：本机 macOS、Apple Silicon。代码基线：`0cd803b`。测试使用独立应用配置；本机创作库更新另有完整备份和哈希核对。

## 自动化与安装包

- `npm run check` 通过设计检查、三应用类型检查、119 个测试文件中的 561 个测试，以及工作区构建。
- 后续 Finder 定位修复与项目名称规范化分别有失败复现，再通过针对性测试；最终 `lotteryCompanion.test.ts` 和 `desktopCompanion.test.ts` 合计 18 个测试通过。再次执行共享设计检查、类型检查和差异空白检查。
- 开发版与 0.1.11 候选安装包均通过五组既有真实 Electron 流程：统一项目创作、原生编辑到本机应用、订阅/导入/Codex MCP、Provider 配置、视频注视。没有付费生成调用；生成流程使用测试 Provider。
- 新增安装包流程验证全部 11 个手动动作、12 个状态、78 张帧、36 条连接；实际窗口奔跑与停止；原生八方向注视；拖拽项圈、放下回程；持有宠物时收到权限与完成事件，放下后再响应；浅色与暗色设置。未出现页面异常。
- 工作提醒通过真实辅助子进程传入测试 hook JSON，验证持续刨坑超过两个循环、像素帧变化、公开小标题、权限提醒和完成提醒；这不等同于用户真实 Codex 会话已接通。
- 最终发行包通过 `codesign --verify --deep --strict` 和 `hdiutil verify`。这是本地签名验证，未进行公证发布。

## 真实 Desktop 测试

最终发行包在独立 PetLord 配置中，使用本机真实 Desktop 进行两次动作测试。两份文件均创建成功，Finder 读回位置与指定的宠物脚边坐标一致，自定义图标属性存在，无效果警告；随后通过应用将两份自有测试文件移入废纸篓。

关闭开关不生成文件、完成才创建、重复事件与重启去重、打断不创建、文件替换后拒绝清理等行为另有自动化覆盖。早期测试发现 Finder 的桌面视图选项查询会阻塞，最终实现已移除该查询，直接放置并读回核对自己的文件，不修改 Finder 的全局排列设置。
