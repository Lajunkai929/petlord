# 彩票像素陪伴

PetLord 0.1.13 中的「彩票 · 原生像素逐帧版」包含 12 个状态、80 张可编辑源帧和 36 条动画连接。画布始终是 48 × 48，使用原生像素数据、图层与明确的帧时长绘制；放大采用最近邻采样。原有坐、趴、睡等20张源帧保留，侧身动作、悬垂、奔跑、刨坑与过渡稿已经重画。

## 使用与继续创作

「设置 → 行为 → 日常互动」提供坐着、站立、趴下、睡觉、翻肚皮、伸懒腰、跑一跑、拉粑粑、尿尿、刨坑和打招呼。点击「停止动作」回到初始状态。奔跑会移动桌面上的宠物，并在当前显示器工作区内转向。

左键单击仍是默认互动。坐着和趴着时，宠物用八个方向的完整头部姿态注视附近鼠标，耳根、眼眉、腮部和口鼻共同转动。方向边界的小幅鼠标移动不会反复闪帧，大幅转向经过相邻姿态。拖拽会进入侧身提项圈姿态，躯干向下倾斜、四肢松垂，锚点位于项圈；放下后播放回程。拖拽期间收到的任务提醒会等到放下再响应。

从「宠物 → 编辑这个宠物」进入原项目，在「绘图」里修改每帧、图层和调色板，在「状态与动作」里调整动作关系。保存后到「发布 → 更新本机宠物」，直接更新正在使用的安装，无需导出再导入。`.petlord` 导出包用于分享，也保留可编辑源码。

状态图节点、右侧参考图和锚点预览会显示完整的原生画布。点击预览可按整数倍放大查看，透明区域保留棋盘格。被替换的生成姿态保留素材历史；没有被自定义过渡使用的旧姿态移为草稿，避免继续参与桌面播放。

## 真实桌面文件

「留下真实的桌面纪念」默认关闭。关闭时只播放动作；开启后，每次完整的便便或尿尿动作会在系统 Desktop 目录创建一份唯一命名的文本文件，分别设置粑粑或尿渍图标，并尝试放到宠物脚边。

文件只在动作完成时创建，中断或重复播放进度不会重复生成。设置页列出仍存在的小纪念，可逐份移到废纸篓；只清理 PetLord 创建且之后没有被替换或修改的文件。关闭开关不会删除之前的文件。

自定义图标和定位目前实现于 macOS。若系统权限、Finder 排列或显示器布局阻止定位，文件仍然保留，设置页会显示未完成的效果。本轮在本机真实 Desktop 上验证了两类图标、准确位置和清理；没有验证其他操作系统或所有多显示器布局。

## Codex 工作状态

打开「设置 → 接入 Agent → 任务提醒 → 配置任务提醒」。PetLord 会备份并合并配置、安装本机通知辅助程序并启用 Agent 动态插件，保留已有通知及其他 hooks。

首次使用需在 Codex 的 `/hooks` 中审查并信任 PetLord hooks，然后开始一个任务。此步骤来自 [Codex 官方 hooks 机制](https://learn.chatgpt.com/docs/hooks)。保持 PetLord 运行；「发送自测提醒」仅验证提醒通路，真实任务接通后才会显示「已收到真实任务」。

当前像素项目只配置一条工作的刨坑循环：工作期间持续播放，完成、需要操作或中断时切换动作。多个任务分别跟踪，单个任务结束不会抹掉其他任务的工作状态。可手动停止动作；后续的新工作事件会重新开始工作循环。

气泡优先使用结构化公开摘要中的短小标题，再使用可见进度或具体工具状态；不展示摘要正文、加密内容或原始分析内容。标题随 hook 事件更新，Codex 没有提供标题时会显示明确的状态。公开摘要与原始内容是不同字段，见 [Codex App Server 文档](https://learn.chatgpt.com/docs/app-server)。

## 开发入口

- 画稿：`packages/pixel-art/src/examples/lottery-companion.json`。
- 完整项目构建：`apps/generation-api/src/lotteryCompanion.ts`；调用者负责媒体导入与带版本号的项目保存。
- 原生注视：状态的 `pointerGaze.nativeImageArtifactIds`，固定八个方向；格式与保存流程见 [Agent 设计协议](agent-design.md)。
- 工作动作：语义键 `working`，本项目映射到 `digging`。循环使用已有状态闲置动画调度，不依靠反复播放长视频。
- 桌面文件：`desktop-companion.cjs` 管理动作完成与文件归属，`desktop-waste-platform.cjs` 负责平台效果。发行版附带编译后的图标辅助程序，无需用户安装 Swift 工具链。
- 界面继续使用 [PetLord 设计规范](design-system.md)及仓库 Skill。

最初的功能验证见 [像素陪伴验证记录](pixel-companion-verification.md)，最新的绘画与显示修正见 [像素质量验证记录](pixel-quality-verification.md)。
