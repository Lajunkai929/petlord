# 模型服务配置

适用于 PetLord 0.1.8。

## 添加和选用服务

1. 打开 Studio，点击左侧底部的 **模型**，进入全局「模型服务」。
2. 点击 **添加服务**。先选择火山方舟、OpenAI、硅基流动，或 **其他服务**。
3. 在配置对话框中填写服务名称、生成用途、调用协议、Base URL、API Key 和模型列表。预设会填好地址、协议和参考模型；这些值仍可修改。模型 ID 输入后按 Enter 添加，也可以填写自己的部署 ID。
4. 保存后可 **验证连接**、编辑、启用或删除。验证连接只查询模型接口，不执行图片或视频生成。
5. 回到项目的 **生成设置**，选择已保存的图片／视频服务及其模型。一个服务可供多个项目使用。

同一厂商的图片和视频连接按用途分别保存。编辑现有连接时用途固定；需要另一用途时添加一个新连接。已删除或停用的项目连接会显示提示，用户重新选择后才会更换。

生成设置会展示模型实际支持的尺寸：硅基流动 Qwen Image 使用 1328 × 1328，Qwen Edit 的尺寸由模型和参考图决定，无法指定的清晰度不会显示为可选项。切换到方舟 Seedream 5 会自动采用它支持的 2K 最低档。

## 协议和预设

| 选择 | 默认地址 | 当前支持 |
| --- | --- | --- |
| 火山方舟 | `https://ark.cn-beijing.volces.com/api/v3` | 图片、异步视频任务 |
| OpenAI | `https://api.openai.com/v1` | OpenAI Images JSON 图片生成与编辑 |
| 硅基流动 | `https://api.siliconflow.cn/v1` | SiliconFlow Images 图片生成与编辑 |
| 其他服务 | 自行填写 | 选择上面已实现的调用协议 |

厂商预设和调用协议是独立设置。模型列表会保存在本机，不受预设模型白名单限制；模型必须在对应服务端实际可用。

「OpenAI Images」采用 `/images/generations`，参考图编辑采用 JSON `/images/edits` 的 `images: [{image_url}]`。只提供 Chat Completions 或 multipart 编辑接口的代理需要另加协议适配。硅基流动的参考图数量和输出尺寸取决于模型；不支持的组合会明确报错。当前视频适配为火山方舟。

协议实现依据：[OpenAI Images 编辑接口](https://developers.openai.com/api/reference/resources/images/methods/edit)、[硅基流动 Images API](https://docs.siliconflow.cn/docs/api/images-generations-post)、[硅基流动图片能力说明](https://docs.siliconflow.cn/docs/userguide/capabilities/images)。

## 费用、密钥和表单行为

- 可填写每个模型的 **预算预估**：图片为元／张，视频为元／秒。未内置价格的模型可以先保存连接，生成前需补充预估费用。系统用它检查项目预算；实际账单由服务商结算，界面不会把估算标成实耗。
- API Key 保存后，列表只返回脱敏提示。编辑时留空会保留原密钥；填写新值才替换。
- **取消**、关闭或 Escape 放弃本次草稿，不保存；校验或网络错误保留在对话框内，可修改后重试。保存过程中避免重复提交和意外关闭。
- 服务端确认保存后，连接即显示为已保存；后续列表刷新失败只显示连接状态提示，不会让用户误以为保存失败而重复添加。
- 正在被生成任务使用的连接不能编辑或删除，任务完成后再操作。
- 身份库和风格库的新建同样使用独立对话框；创建成功后进入对应内容的编辑区。

适配器和界面已使用本地模拟服务验证，尚未使用真实厂商密钥进行付费生成测试。
