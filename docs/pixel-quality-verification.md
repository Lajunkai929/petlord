# 像素显示与动作质量修正 · 0.1.13

日期：2026-09-10。基线：`2449e05`。用户指出眼睛单独移动不自然、Studio 状态图被裁切，以及侧身和中间帧形体错误。本轮分别修正显示容器、方向切换机制和原生画稿。

## 显示与注视

真实复现发现：节点198×118的媒体区中，图片被自然尺寸撑到198px高；右侧320×190参考区中，Ant Design 的 `height: auto` 把图片撑成318×318。显式传递图片尺寸、允许网格收缩后，图片分别为198×117、318×188，采用contain完整显示。原生图像的最近邻显示贯穿节点、缩略图、右侧、历史版本、注视/拖拽/触发锚点与放大查看。原生放大图初始按整数倍显示，照片保持普通插值。

坐姿和趴姿各重画8张头部注视帧：保留原眼眶、暖色眉斑和宽口鼻，调整近远耳根、腮部、面部朝向与颈部接缝。原生方向调度增加6.75°滞回，每75ms最多进入一个相邻方向；快速改变目标不排队，动作/拖拽/退出立即取消，没有淡化混像素。

## 画稿与时序

站立、跑、蹲下、抬腿、提起、刨坑、翻肚皮和招呼重新处理了身体体积、近远四肢和尾根。提起时项圈受力点保持在约(21,25)，躯干向右下倾斜，四肢随骨盆下坠。起身、低头和离地使用不同的关节姿态；翻肚皮先经过趴下/侧躺，跑步使用交替支撑，刨坑具有伸出、刨回、收回阶段。

画稿为48×48、80张源帧、12个状态、36条动画连接。原20张源帧和旧素材记录保留。被替换的生成姿态退为草稿，仍被已有自定义过渡使用的变体保留批准状态。已检查角色主体的像素连接，排除土粒/排泄表现后没有明显分离的躯体部件。

独立逐帧美术审查查看了全部关键姿态及起身、提起、跑、挖、翻肚皮、排泄和坐趴睡连接。当前形体连贯、动作可辨，提起已有下坠感。它仍是少量关键帧的风格化动画，翻身的头部旋转有卡通省略；测试数量不作为美术水平的证明。对比动图用相同的原生渲染与放大方式制作，没有故意模糊旧稿。
