## 此次复核补齐的问题

- 相同包按不同安装 key 保留两份时，各自建立可编辑项目，更新其中一份不会改动另一份。
- 删除关联项目后，点击宠物的编辑按钮即可从安装包恢复；旧版本的写请求仍被版本保护拒绝。
- Provider 保存、修改、删除以服务端成功回执为准，后续列表刷新失败不会诱导重复提交。旧读请求也不能覆盖已确认的写结果。
- 硅基流动 Qwen 模型的固定或模型决定尺寸明确展示；不能生效的尺寸选项禁用。选择方舟 Seedream 5 时同步采用 2K 最低档。
- MCP 等待默认 30 秒、单次最多 45 秒；仍在生成时返回任务和可重试提示，使用原 jobId 继续等待。修复前的真实 SDK 复现会在 60 秒触发客户端超时，修复后约 30 秒正常返回。这与 [Codex 默认工具时限](https://learn.chatgpt.com/docs/extend/mcp) 相容。
- 订阅地址改为对话框草稿，取消不保存，连接成功才记住地址。真实本地订阅服务验证浏览、下载、同 key 更新和继续使用。

上述重要修复均由独立复核关闭。测试先复现了导入关联、恢复、Provider 刷新、模型尺寸和 MCP 等待缺陷，再验证修复。

## 结论的边界

原生像素例稿已具备可编辑状态和逐帧动画；艺术表现是否达到《星露谷》制作水准是独立的视觉判断，不能由功能测试证明。当前例稿仍作为原创试稿提供。

生成适配器通过本地模拟服务及实际媒体处理验证，没有使用真实厂商密钥进行付费生成。当前视频适配为方舟，OpenAI 兼容适配指 JSON Images 接口。旧运行包未曾保存的原始提示词、候选历史和图层拆分无法凭空恢复。具体操作见 [Agent 与原生像素创作](agent-design.md) 和 [模型服务配置](model-services.md)。
